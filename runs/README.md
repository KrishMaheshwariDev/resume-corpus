# Optimization Runs

Optional location for persistent optimization reports.

Recommended per-run contents:

```text
runs/YYYY-MM-DD-company-role/
  optimization_report.yml
  notes.md
```

A report may record:
- source resume and target;
- baseline/final scores;
- page count;
- hard requirements;
- evidence promoted;
- claims excluded for truthfulness;
- keyword/skill changes;
- validation results;
- commit SHA.

Do not commit transient build artifacts here.
