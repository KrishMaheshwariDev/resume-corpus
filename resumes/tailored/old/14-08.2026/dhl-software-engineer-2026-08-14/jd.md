# DHL IT Services — Software Engineer

Source: Job description supplied by the user on 2026-08-14.

## Core responsibilities

- Build and maintain backend services for DHL Express applications.
- Ensure performance, reliability, scalability, security, and compliance across distributed systems.
- Provide third-level operational support and investigate incidents with other support teams, specialists, and vendors.
- Use AI tools for coding assistance, test generation, refactoring, documentation, troubleshooting, and root-cause analysis.

## Requirements

- Strong Java, Spring Boot, and microservices knowledge.
- Familiarity with PostgreSQL, IBM MQ, GitHub Actions CI/CD, and Linux.
- Understanding of Podman, Kubernetes, and cloud-native development.
- React is a plus.
- Independent work, global collaboration, and good written/spoken English.
