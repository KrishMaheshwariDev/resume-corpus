# Thermo Fisher Scientific - Software Engineer II

## Role focus

Develop and maintain software for scientific instruments and platforms using modern cloud services and microservices, in collaboration with cross-functional teams.

## Required capabilities

- Bachelor's or master's degree plus at least two years of development experience
- Object-oriented programming and design patterns
- Java, Spring, and Hibernate
- CI/CD, version control, automated testing, and maintainable documentation
- Agile delivery, including Scrum or SAFe
- AWS and microservices
- Database design and SQL
- Git, JIRA, and modern development environments
- Problem solving, communication, collaboration, and rapid learning
- UI/web technologies and software-security knowledge are advantageous

## Evidence boundary

AWS is project-backed rather than production cloud ownership. Scrum is verified; SAFe is not. UI experience combines professional JSF/AJAX, Angular training delivery, and React projects. Enterprise security-boundary experience is supported, but security architecture ownership and scientific-instrument domain experience are not claimed.
