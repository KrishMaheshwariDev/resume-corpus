Source: user-provided job description.

- 4+ years of backend Java and full SDLC experience, with full-stack breadth.
- Design, coding, testing, debugging, documentation, deployment, maintenance, and Agile teamwork.

- Python and Bash scripting.

- AWS Lambda, Kinesis, API Gateway, IoT, and IoT-project exposure.

- AWS Lambda, ECS, RDS, S3, Docker, and Terraform are project-backed.
