# Software Engineer — India (Associate Level)

## Role summary

- Engineer and maintain innovative, customer-centric, high-performance, secure, and robust software.
- Work in a permanent feature team across the full software lifecycle.
- Collaborate with engineers, architects, business analysts, and platform stakeholders.
- Design, produce, test, deploy, operate, enhance, maintain, and eventually replace software solutions.

## Key requirements

- Software engineering, software design, and architecture background.
- Strong problem-solving aptitude and proactive, self-driven communication.
- Hands-on AWS evidence, particularly IaC, ECS/EKS, or general enterprise AWS architecture.
- Expert knowledge of Java 21, Node.js, or Python.
- Effective use of AI coding assistants with human review, including agentic IDEs such as Kiro or Claude.

## Evidence boundaries used for tailoring

- Verified professional Java versions: Java 8/11; Java 21 is not claimed.
- AWS, Terraform, Docker, and ECS are supported by project evidence, not production employment.
- No verified EKS or production enterprise AWS architecture ownership.
- AI-assisted development is represented as project use with human validation; Kiro and Claude are not claimed.
