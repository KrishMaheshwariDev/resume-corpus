# Resume Variants

`resume.tex` / `Resume.pdf` at repository root remain the canonical general-market resume.

Use this directory for variants that should not overwrite the canonical baseline.

Recommended structure:

```text
resumes/
  general/
    README.md
  tailored/
    <company-role-YYYY-MM-DD>/
      resume.tex
      Resume.pdf
      jd.md
      optimization_report.yml
```

Tailored variants may omit low-relevance skills/content, but omissions do not modify the factual profile corpus.
